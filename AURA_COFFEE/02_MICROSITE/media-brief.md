# Coffee — Media Brief

Every media slot on the coffee microsite, in scroll order. Generated from the
live page code, so the list matches what is actually built.

## How these are used

Every slot is a **full-bleed background**. The CSS is `min-height: 100svh` with
`object-fit: cover`, so the image fills the viewport and crops — it is never
letterboxed and never sits in a box.

**Deliver per slot**

| | |
|---|---|
| Landscape master | 3840 × 2160 (16:9) — desktop |
| Portrait crop | 1440 × 2560 (9:16) — mobile, same frame re-cropped |
| Video | same two ratios, H.264 mp4, 8–14s silent loop, plus a poster still |
| Colour | shot to sit under a dark scrim; mid-tones hold up better than high contrast |

**Composition rule.** Type sits bottom-left over the scrim. Keep the lower-left
third quiet — no faces, no busy detail, nothing that competes with white text.

**Slots marked KEEP BLACK stay unfilled.** The empty scenes are the pacing of the
scroll. Filling all 54 would flatten the whole thing — the black is doing work.

**Totals.** 54 slots — 35 carry media, 19 stay black.
