# Claims ledger

Every factual claim the site makes that a reader could check, with where it
comes from and how confident we are.

The controlling document is `AURA_COFFEE/01_STRATEGY/claims-and-proof.md`,
which classifies each claim and states whether it may be published. This
ledger records what the site currently says and what backs it.

**Confidence**

| | |
|---|---|
| **Verified** | A first-party record exists and has been seen. |
| **Estate record** | Aura's own log or register. Trusted, not independently audited. |
| **Reading** | An interpretation of facts. Published as an interpretation. |
| **External** | Published science or a public listing, cited below. |
| **Unverified** | Stated on the site, no record seen. Flagged in `open-questions.md`. |
